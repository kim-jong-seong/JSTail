# JSTail

실시간 로그 뷰어. 파일에 새로 쌓이는 내용을 따라가며 보여줍니다.

Windows / Python 3 + Tkinter

## 기능

### 로그 보기

- 파일이 커지는 만큼만 읽어 이어붙입니다 (500ms 주기)
- **자동 스크롤** — 맨 아래에 있으면 새 로그를 따라가고, 위로 올리면 읽던 위치를 지킵니다
- 위로 올린 사이에 로그가 들어오면 하단에 **`새로운 로그`** 버튼이 뜹니다
- 화면에 유지할 줄 수를 넘으면 오래된 줄부터 정리합니다 (기본 50,000줄)
- 로그 창은 읽기 전용이라 실수로 타이핑되지 않습니다

### 인코딩

`자동` / `UTF-8` / `CP949` 중에서 고릅니다. `자동`은 BOM을 먼저 보고, UTF-8로 읽었을 때
깨지는 비율로 판단합니다. 읽는 도중 글자가 깨지면 다시 판단해 고쳐 읽습니다.

### 하이라이트

키워드마다 색을 지정해 강조합니다. 로그 창에서 **문자열을 드래그한 뒤 `Ctrl+H`** 를 누르면
키워드가 자동으로 채워지고, 이미 쓰는 색과 겹치지 않는 파스텔 색이 함께 지정됩니다.

### 구분선

`Ctrl+D` 로 지금 시각이 찍힌 구분선을 넣습니다. 배포하고 기능을 눌러보기 직전에 그어두면
그 아래부터가 방금 발생한 로그입니다.

```
──────────────  2026-09-10 16:14:59  ──────────────
```

넣고 나면 `F2` / `Shift+F2` 로 오갈 수 있다고 잠깐 알려줍니다. 이동할 때마다
`구분선 3 / 5` 처럼 몇 번째인지도 표시됩니다. 창 크기나 글꼴을 바꾸면 선 길이도
다시 맞춰집니다.

### 배경색

`Ctrl+B` 로 여는 창에서 색상 코드를 직접 입력하거나, 옆 색 칸을 눌러 Windows 색 선택 창으로
고릅니다. 자주 쓰는 색은 **이름을 붙여 저장**해두고 목록에서 골라 쓸 수 있습니다.
파스텔톤 기본 색 다섯 개가 들어 있습니다.

### 그 밖에

- **찾기** — 일치하는 것 전부 표시, 현재 항목만 진하게, `3 / 27` 개수 표시.
  `Enter` / `F3` 로 다음, `Shift+Enter` / `Shift+F3` 로 이전. 문자열을 드래그한 뒤 `Ctrl+F` 를
  누르면 검색어가 채워집니다. `위로` / `아래로` / `매치` 를 바꾸면 바로 다시 찾고,
  찾는 중에 들어온 로그도 이어서 표시합니다.
- **최근 파일** — 최근에 연 파일 5개를 하위 메뉴에서 고릅니다
- **드래그 & 드롭** — 파일을 창에 끌어다 놓으면 열립니다
- **항상 위** (`Ctrl+T`), **제목 표시줄 숨기기** (`Ctrl+E`)
- 글꼴 / 크기 변경, 빈 줄 지우기

## 단축키

| 키 | 기능 |
| --- | --- |
| `Ctrl+O` | 파일 열기 |
| `Ctrl+Space` | 맨 아래로 |
| `Ctrl+F` | 찾기 |
| `F3` / `Shift+F3` | 다음 / 이전 찾기 |
| `F2` / `Shift+F2` | 다음 / 이전 구분선 |
| `Ctrl+D` | 구분선 넣기 |
| `Ctrl+H` | 하이라이트 |
| `Ctrl+L` | 화면 지우기 |
| `Ctrl+Q` | 빈 줄 지우기 |
| `Ctrl+B` | 배경색 |
| `Ctrl+T` | 항상 위 |
| `Ctrl+E` | 제목 표시줄 숨기기 |
| `Alt` + 드래그 | 창 이동 (제목 표시줄을 숨겼을 때) |

나머지 기능은 로그 창에서 **오른쪽 클릭** 하면 나옵니다.

## 설정

설정은 아래 위치에 저장됩니다. 실행 파일을 어느 폴더에서 실행하든 같은 설정을 씁니다.

```
%APPDATA%\JSTail\config.ini
```

예전 버전처럼 실행 파일 옆에 `config.ini` 가 있으면 처음 실행할 때 한 번 옮겨옵니다.
백업하거나 다른 PC 로 옮길 때는 우클릭 → **설정 ▸ 내보내기 / 가져오기** 를 쓰면 됩니다.

창 위치와 크기, 최대화 여부도 함께 기억했다가 다음 실행 때 되돌립니다.
모니터 구성이 바뀌어 저장된 위치가 화면 밖이면 기본 위치로 띄웁니다.

`max_lines` 를 바꾸면 화면에 유지할 줄 수를 조정할 수 있습니다 (`0` 이면 제한 없음).

## 빌드

```
pip install pyinstaller tkinterdnd2

python -m PyInstaller --onefile --noconsole --name JSTail ^
  --icon icon.ico ^
  --add-data "icon.ico;." ^
  --add-data "<site-packages>\tkinterdnd2\tkdnd\win-x64;tkinterdnd2/tkdnd/win-x64" ^
  --hidden-import tkinterdnd2 ^
  JSTail.py
```

`tkinterdnd2` 는 파일 끌어다 놓기에만 쓰입니다. 없어도 그 기능만 빠지고 나머지는 동작합니다.
